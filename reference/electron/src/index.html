Provider ini dipakai untuk SEMUA tahap AI: ringkasan konteks, deteksi potongan/highlight, hook & judul, dan perbaikan caption.
Gratis di Google AI Studio
Gratis di console.groq.com Akun gratis Groq dibatasi ±200.000 token per hari untuk tiap model (pulih bertahap dalam 24 jam). Cukup untuk beberapa video panjang per hari — satu video 1 jam bisa memakai puluhan ribu token. Kalau muncul "rate limit" atau "tokens per day", ganti Model Groq di bawah (tiap model punya jatah sendiri), tunggu beberapa jam, atau upgrade ke Groq Developer.
Cadangan terakhir: dipakai hanya kalau video tidak punya subtitle DAN tidak ada API key yang bisa dibaca. Groq (gratis) tetap didahulukan karena jauh lebih cepat.
Diunduh sekali saat pertama dibutuhkan, bukan saat install. Perkiraan waktu: sekitar 2-5x durasi video di laptop tanpa GPU — pakai Groq (gratis) kalau bisa.
