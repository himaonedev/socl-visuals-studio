# Portrait segmentation

`selfie_segmenter.tflite` is the MediaPipe Selfie Segmenter model, distributed
under Apache License 2.0. Source:
https://ai.google.dev/edge/mediapipe/solutions/vision/image_segmenter

The model was copied from the local facecammaxxing checkout's `models/`
directory. Its original source is recorded by that project's setup script.
The worker is independently implemented for CutVii. Python, MediaPipe,
NumPy and OpenCV must be installed in the selected local Python runtime.
No media or transcript is uploaded.
